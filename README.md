This repository hosts the site source code. Use the link above to visit the public journal website.

《青年政治评论》是一份面向全球青年读者的中英双语公共思想期刊，关注全球政治、全球经济、全球文明与全球治理。

The Youth Political Review is an independent bilingual journal for young readers interested in global politics, economy, civilization and governance.

## Development

The static site lives in `dist/`. GitHub Pages deploys it through `.github/workflows/deploy-pages.yml` whenever `main` is updated.
